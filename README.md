## 🚀 快速开始

### 方式一：直接使用（推荐）

1. 下载本仓库（网页端 **Code → Download ZIP**，或 `git clone`）。
   若仓库里没有 PDF（默认被 `.gitignore` 排除），到 **Releases** 里下载，或本地重新生成（见下）。
2. 双击 `现代激光原理与技术.pdf` 阅读 / 打印。
3. 想要可复制文字与公式？双击 `index.html`，用浏览器阅读（建议 Edge/Chrome）。

### 方式二：只看网页版

`index.html` 是**完全自包含**的：所有图片、样式都在同目录的 `Material/`、`ext/` 里，
把整个文件夹拷到 U 盘即可断网阅读。侧边栏可按章跳转，浏览器 `Ctrl+F` 全文检索。

### 方式三：手机 / 平板

把 PDF 拷进手机，用系统阅读器或微信读书、Adobe Acrobat 打开；763 页带书签，可跳章。

## 🔧 技术记录：这些文件是怎么拿到的

> 这一节是给想复现、想帮别人做同样事情的同学看的。**全过程没有使用、存储或传播任何登录凭据**
> （仓库内不含 Cookie / token），也没有破解任何权限控制——下载的都是服务器上公开可访问的静态资源，
> 请求与普通浏览器访问网页时发出的一致。

### 1. 平台与这本书的标识

| 项 | 值 |
| --- | --- |
| 阅读页 | `https://www.bhpressshuzi.cn/h5/#/szjcDetail?id=1547155808880427008&rdPath=home` |
| 平台 | Keledge 数字内容运营平台，属 **DCD 富内容教材**（不是 PDF/EPUB，所以官方"下载"按钮并不存在） |
| 内容 Id | `1547155808880427008` |
| BookId（资源目录名） | `f3003836-2c78-a048-63f1-4ff6cff7b068` |
| 应用 AppId | `1319214332369698816` |
| 版本 | V1.0.0（`VersionGuid = c13b78e4-2b86-4bee-b143-3f31a0773dab`） |
| 规模 | 58 章 / 41 节 / 2467 个资源元素（其中 1628 个 LaTeX 公式、640 张图、191 个视频） |

### 2. 三个关键接口（均免登录可读）

```http
# ① 书的元数据与内容清单（1.7 MB JSON，2467 个资源元素）
GET https://www.bhpressshuzi.cn:50012/bhcbs/Content/Detail?Id=1547155808880427008

# ② 目录：58 章，每章含 Title 与 Url（章节 HTML 的文件名）
GET https://www.bhpressshuzi.cn/dev-api/webApi/book/getBookCatalog?id=1547155808880427008

# ③ 阅读器授权（阅读器初始化时调用，实际上正文不依赖它）
POST https://www.bhpressshuzi.cn:50012/bhcbs/Content/TextbookAuthorize?appId=1319214332369698816&contentId=f3003836-2c78-a048-63f1-4ff6cff7b068&platform=web
```

### 3. 突破口：正文 HTML 就在资源根目录

目录接口返回的每一项都带一个形如 `./第1章_绪论-99879526-f0e4-fe95-8a6c-46d61b5831db.html` 的 `Url`，
把开头的 `./` 去掉、拼到资源根后面，就是**免登录的静态文件**：

```text
https://www.bhpressshuzi.cn/bhcbs/files/Resource/f3003836-2c78-a048-63f1-4ff6cff7b068/<章节文件名>
                                                      └─────────────── BookId ───────────────┘
```

章节 HTML 内部再以相对路径引用素材（`Material/img/...`、`Material/svg/...`、`ext/...`），
所以只要把「58 个章节 HTML + Material/ + ext/」按同样的目录结构存下来，就是一份完整的离线副本。

### 4. 踩过的四个坑
1. **站点只支持 TLS 1.2**：部分环境用 Python `requests`/`urllib` 直连会
   `ssl.SSLV3_ALERT_HANDSHAKE_FAILURE`。解决办法是用系统 `curl`
   （`curl.exe -sSL --fail --retry 3`），或给 `ssl` 上下文显式锁到 `TLSv1_2`。
2. **中文路径必须百分号编码**：章节文件名是中文，拼 URL 前用 `urllib.parse.quote()`。
3. **别试图一次打印整本书**：合并后的 `index.html` 约 66 万像素高（≈763 页），
   一次性 `printToPDF` 会把浏览器内存顶到 8 GB 以上并长时间不返回；
   正确做法是**逐章打印再合并**（见 `scripts/rebuild_pdf.py`，每章 1.7–12 秒）。
4. **临时脚本别用标准库同名**：曾把脚本存成 `struct.py`，导致
   `ImportError: cannot import name 'iter_unpack' from 'struct'`。

### 5. 复现步骤（最小可用版本）

```bash
# 1) 拿目录（58 章，含每章文件名）
curl -sSL "https://www.bhpressshuzi.cn/dev-api/webApi/book/getBookCatalog?id=1547155808880427008" -o catalog1.json

# 2) 逐章下载（文件名是中文，记得百分号编码；-L 跟随 nginx 301）
#    资源根：https://www.bhpressshuzi.cn/bhcbs/files/Resource/f3003836-2c78-a048-63f1-4ff6cff7b068/
#    章节 URL = 资源根 + catalog 里的 Url（去掉开头的 "./"）

# 3) 从章节 HTML 里抽出所有 Material/... 与 ext/... 引用，按同样路径下载
# 4) 把 58 章按顺序拼成一个 index.html，注入侧边导航与 @page A4 打印样式
# 5) 逐章打印 PDF 并合并加书签：python scripts/rebuild_pdf.py
```

### 6. 抓取时的克制

全部请求都是串行/低并发（不超过 3–4），带失败重试与断点续传；
素材总量 780 MB、章节 HTML 仅 7.0 MB——没有对出版社服务器造成压力。
**请勿把这里的脚本用于批量镜像整站。**

## 🎬 视频（191 个，本仓库未收录）

书里共有 **191 个 mp4**（`Material/video/`，合计约 5.1 GB），**没有放进本仓库**，原因有三：
体积占 87%、GitHub 单文件与仓库体积限制、视频的版权风险。

它们的地址同样是免登录的静态文件。可通过以下方式自行下载：

```bash
python scripts/download_videos.py --dry-run     # 先看清单（191 条）
python scripts/download_videos.py --jobs 3      # 再下，默认存到 Material/video/
```

脚本会读 `metadata/detail.json`，筛出 `PrefaceType == "video"` 的记录，
用 `curl` 断点续传下载，并生成 `video_manifest.csv`（章节 / 原名 / URL / 本地路径），
按它就能把视频对回书里。

## 🖨️ 重新生成 PDF

仓库里如果没带 413 MB 的 PDF，可以本地重建：

```bash
python -m pip install pypdf          # 国内可加：--proxy http://127.0.0.1:7890
python scripts/rebuild_pdf.py        # 逐章打印 → 合并 → 加 58 条书签
```

- 依赖本机 Edge 或 Chrome（脚本自动找路径，也可 `--browser` 指定）；
- 逐章打印，每章 1.7–12 秒，全书约 4 分钟；
- 产物约 763 页 / 413 MB，可直接打印（A4，沿用书稿自带的 `@page{size:A4;margin:16mm 14mm}`）。

只想试几章：`python scripts/rebuild_pdf.py --only 1-3 --keep-temp`。
